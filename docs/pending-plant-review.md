# Fila de Revisão Botânica — Encerrada

Esta fila cobria 19 produtos de Ervas e Temperos sem perfil botânico publicado, por nomes comerciais ambíguos (ex.: "Boldo-miúdo", "Saião").

A decisão do responsável pelo catálogo (2026-08-28) foi publicar a identificação mais provável para cada nome comercial, sem exibir aviso de baixa confiança na interface — o risco de identificação incorreta foi assumido pelo responsável pelo catálogo. Os 19 itens agora têm perfil publicado em `src/data/plant-knowledge-flowers.generated.ts`, junto com a cobertura completa da categoria Flores e Plantas (284 produtos). Ver `docs/plant-knowledge-report.md` para o registro completo.

Este arquivo é mantido apenas como histórico da fila original.
